# FORMA — шаблон барбершопа

Адаптивная страница на HTML, CSS и Tailwind CSS 4, без React.

## Запуск
Откройте dist/index.html в браузере. Для Tailwind и Google Fonts нужен интернет. Tailwind подключён через Browser CDN для простого редактирования шаблона; для промышленного использования соберите утилиты Tailwind локально.

## Файлы
- dist/index.html — разметка и Tailwind-классы.
- dist/styles.css — фирменные стили, адаптивность и шрифты.
- dist/script.js — мобильное меню, выбор услуги/мастера, валидация формы.

## Настройка
Замените название, цены в Kč, состав команды, адрес и часы работы в index.html. Основной акцентный цвет задаётся переменной --orange в styles.css (и Tailwind-классами в HTML).

Форма демонстрационная: она не отправляет и не сохраняет персональные данные, не проверяет доступность дат и не создаёт бронирование. Подключите собственный backend или сервис записи для приёма заявок.

Фотография: https://www.brawnbarbershop.co.nz/services (Unsplash image DrG4V5skbMY). Перед коммерческим запуском замените фотографию собственным материалом или подтвердите условия лицензии.
